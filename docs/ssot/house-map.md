# Mapa da Habitação

## Objetivo

Este documento estabelece a correspondência entre a infraestrutura digital e a infraestrutura física da habitação.

O seu objetivo é permitir identificar:

- onde se encontra cada equipamento;
- qual a sua função;
- quais as dependências;
- quais os serviços associados.

Este documento complementa:

```text
asset-inventory.md
```

Enquanto o inventário responde:

"Que equipamento existe?"

este documento responde:

"Onde está esse equipamento?"
