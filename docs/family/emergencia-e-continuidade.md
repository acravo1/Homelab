# Emergência e Continuidade

## Objetivo

Este documento foi criado para garantir que os serviços digitais da família continuam utilizáveis mesmo na ausência temporária ou prolongada do administrador principal.

O objetivo não é ensinar administração de sistemas.

O objetivo é permitir identificar:

- onde estão os dados;
- como aceder aos serviços;
- o que fazer perante problemas comuns;
- quando pedir ajuda externa.

---

# Regra Mais Importante

Não entrar em pânico.

A maior parte dos problemas tem solução.

A maior parte dos dados continua a existir mesmo quando um serviço parece indisponível.

# O Que Fazer Se Um Serviço Não Abrir?

## Passo 1

Confirmar Internet.

Abrir uma página qualquer.

Exemplo:

```text
www.sapo.pt
```

---

## Passo 2

Verificar VPN.

Se estiver fora de casa:

```text
WireGuard
Ligado
```

---

## Passo 3

Tentar novamente após alguns minutos.

---

## Passo 4

Consultar a FAQ.

# O Que Fazer Se o Nextcloud Não Estiver Disponível?

Verificar:

- ligação à Internet;
- VPN;
- endereço correto.

Os documentos continuam armazenados.

A indisponibilidade temporária não significa perda de dados.

---

# O Que Fazer Se o Paperless Não Estiver Disponível?

Os documentos permanecem armazenados.

Apenas a interface de consulta pode estar indisponível.

---

# O Que Fazer Se a Casa Inteligente Não Funcionar?

Em muitos casos:

- luzes continuam a funcionar;
- equipamentos continuam a funcionar;
- tomadas continuam operacionais.

O Home Assistant acrescenta automatização.

Nem tudo depende dele.

---

# O Que Fazer Se o Servidor Estiver Desligado?

Verificar:

- energia elétrica;
- router;
- UPS (se existir);
- tomadas.

Não efetuar alterações sem compreender o impacto.

---

# Quem Pode Ajudar?

Consultar:

```text
Manual da Família
FAQ
```

antes de procurar assistência externa.

# Informação Importante

Os dados importantes da família foram concebidos para existir de forma organizada e recuperável.

A infraestrutura pode falhar.

Os dados não devem desaparecer por causa disso.

---

# Filosofia

Este sistema foi construído para servir a família.

Não foi construído para depender permanentemente de uma única pessoa.

O objetivo da documentação é precisamente garantir que o conhecimento permanece acessível, mesmo quando o administrador não está disponível.

---

# Mensagem Final

Se está a ler este documento porque surgiu um problema, lembre-se:

A infraestrutura foi concebida para ser recuperada.

A documentação foi criada para ajudar.

Os dados importantes continuam a ser mais valiosos do que qualquer equipamento ou aplicação.

Concentre-se primeiro em proteger e recuperar a informação.

Tudo o resto pode ser reconstruído.
